## AntiOS 会检查什么

- Microsoft Defender 与实时保护；
- BitLocker/设备加密；
- 安全启动与 TPM；
- 系统盘剩余空间；
- 是否有待完成的重启；
- 常见启动应用；
- Windows 版本与内部版本；
- 架构、处理器和运行时间。
