System context

Privacy by design

No automatic telemetry.

AntiOS does not automatically upload diagnostic reports to the project. File scans are read-only; quarantine and restore require confirmation. The installed antivirus provider may use cloud services under its own settings. Defender scans follow Defender's remediation policy.
