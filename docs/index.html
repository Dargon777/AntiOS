AntiOS

Endpoint security, diagnostics and storage tools for Windows, with supplemental Linux companion support.

What it does

AntiOS provides on-demand scanning, optional resident protection, quarantine and restore, security diagnostics, storage cleanup/intelligence, local incident views and recovery tools.

Security posture

AntiOS is pre-release software. It does not claim certified primary Windows antivirus status, ELAM/PPL or perfect pre-execution coverage. It is designed to report degraded or incomplete coverage instead of silently treating failures as clean results.

Privacy

AntiOS does not include automatic project analytics or telemetry. Review exported diagnostics before sharing them.

Architecture documentation

Public documentation intentionally stays at the capability and limitation level. Internal trust sequencing, service/task identities, state/IPC layouts, detection thresholds, update/repair handoffs and native protocol details are not published here.
