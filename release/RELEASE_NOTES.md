# AntiOS 3.0.01 Alpha

This alpha introduces AntiOS Engine as the built-in offline scanner on Windows and Linux.

- Manual scans and Guard use a shared signed catalog with 47 curated SHA-256 indicators.
- File scans support more archive formats and flag incomplete inspection.
- Windows setup reports when a previous installation needs to be removed through its own uninstaller before installing this version.

AntiOS remains prerelease companion software with a limited signature catalog.
