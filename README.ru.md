# AntiOS

[English](README.md) · **Русский** · [Español](README.es.md) · [简体中文](README.zh-CN.md) · [Suomi](README.fi.md) · [Polski](README.pl.md) · [Монгол](README.mn.md)

AntiOS — проект endpoint-security и обслуживания системы для Windows с дополнительным режимом-компаньоном для Linux.

> **Предварительная версия:** AntiOS v2 alpha

## Возможности

- проверка файлов и папок по запросу;
- опциональная резидентная защита;
- карантин и восстановление;
- совместная работа с поддерживаемыми сторонними антивирусами;
- диагностика безопасности Windows и системы;
- очистка и анализ хранилища;
- ограниченное резервирование/восстановление файлов;
- локальная диагностика и просмотр инцидентов;
- обновление, установка и восстановление компонентов с безопасными отказами.

## Загрузка

Используйте последний опубликованный установщик или portable-пакет на странице Releases:

https://github.com/Dargon777/AntiOS/releases

Целевая поддержка: Windows 10 22H2 x64 и более новые версии Windows 11. Linux-режим является дополнительным.

## Безопасность и приватность

AntiOS по умолчанию обрабатывает диагностические и защитные данные локально и не включает автоматическую телеметрию.

В публичной документации намеренно не публикуются чувствительные внутренние детали: точный порядок взаимодействия компонентов, границы доверия и их последовательность, механика автозапуска/персистентности, внутренние файлы состояния и IPC, имена и устройство служебных задач/сервисов, форматы восстановления, пороги детектирования, параметры очередей/кэшей, детали native-протоколов и внутренний handoff обновления/repair.

Публично остаются возможности продукта, ограничения и пользовательское поведение. Это уменьшает ценность готовой разведки, но не заменяет безопасную архитектуру, подпись обновлений, минимальные привилегии и ревью кода.

См. [SECURITY.md](SECURITY.md) и [PRIVACY.md](PRIVACY.md).

## Антивирус

Раздел «Антивирус» предоставляет сканирование, результаты, карантин, состояние защиты и расширенную диагностику. AntiOS может работать рядом с Microsoft Defender и поддерживаемыми сторонними продуктами, не отключая их защиту.

Резидентная защита и экспериментальные native-компоненты описываются только на высоком уровне. AntiOS пока не заявляет сертифицированный статус основного антивируса Windows, ELAM/PPL или полное предотвращение запуска угроз.

Подробнее: [docs/ANTIVIRUS.md](docs/ANTIVIRUS.md).

## Хранилище и восстановление

Storage Cleanup работает только с явно подтверждёнными действиями. Функции восстановления файлов — это ограниченные средства резервирования и проверки целостности, а не полный rollback Windows и не гарантия отсутствия вредоносного содержимого.

## Установка

Для обычной Windows-установки используйте последний `AntiOS-Setup.exe` из Releases. Portable ZIP предназначен в основном для переносного/разработческого сценария.

Внутренние детали установки, сервисов, задач и repair-последовательностей публично не документируются.
