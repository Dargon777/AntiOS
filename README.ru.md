**AntiOS — проверка файлов на угрозы, зашифрованный карантин и диагностика Windows.**

**Целевая поддержка Windows:** Windows 10 22H2 x64 (сборка 19045) и более новые версии Windows 11. Старые выпуски Windows 10 и 32-битная Windows не поддерживаются.

Скачайте последний `AntiOS-windows-x64.zip` на странице релизов, распакуйте архив и запустите **`AntiOS-GUI.exe`**:

При запуске Windows запросит права администратора. Распакуйте весь архив: папки `_gui` и `_cli` должны оставаться рядом с EXE. Кнопка «Остановить» принудительно завершает проверку файлов, сохраняя полученные неполные результаты. Издатель в сведениях приложения — DargonITP; подтверждённое имя издателя в Windows требует доверенной цифровой подписи.

## Что проверяет AntiOS

- Microsoft Defender и защиту в реальном времени;
- BitLocker/шифрование устройства;
- Secure Boot и TPM;
- свободное место на системном диске;
- ожидающую перезагрузку;
- приложения автозагрузки;
- версию и сборку Windows;
- архитектуру, процессор и аптайм.

Интерфейс автоматически выбирает русский язык на русской Windows. Язык также можно переключить вручную: **English / Русский / Español / 简体中文 / Suomi / Polski / Монгол**.

## Антивирус в alpha 11

Вкладка **«Антивирус»** (`Ctrl+6`) проверяет выбранные файлы и папки через установленный антивирусный движок Windows AMSI и локальные SHA-256 сигнатуры. Доступны ручной зашифрованный карантин, восстановление без перезаписи, отчёт JSON, быстрая и полная проверка Microsoft Defender и обновление его баз.

Это сканер по запросу: постоянную защиту обеспечивает установленный антивирус. Собственной обновляемой базы вредоносных файлов пока нет; встроена только сигнатура теста EICAR. Архивы не распаковываются. По умолчанию проверяются файлы до 32 МиБ; пропуски и ошибки видны в отчёте. Неполная проверка не считается подтверждением безопасности.

Проверка не изменяет файлы. Карантин, восстановление и действия Defender требуют подтверждения. AntiOS не отправляет автоматическую телеметрию; установленный антивирус может использовать облачную проверку по своим настройкам.
